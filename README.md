## Project Name:
### Bazar-Dor

## Description:
-- Bazar-Dor(বাজার দর) is a Next.js-based web application that helps users explore daily market prices in Bangladesh. Users can browse products bt category,compare current prices with previous prices, track price increases and decreases and view detailed product information. The project aims to make market price information more accessible and help consumers make smarter shopping decisions.

## Using Technologies:
1. Next.js
2. React
3. Tailwind CSS
4. Authentication with Better Auth
5. Skeleton Loading UI
6. Daisi-Ui
7. TypeScript
8. API Intregation


## 5 key features of the project:
### 1. Category Based Product Browsing- 
     Products are organized into categories making it easy for users to find the products they need.
### 2. Price and Tracking-  
    The application highlights price increases and decreases, allowing users to identify products that are becoming more esxpensive or less expensive.

### 3. Detailed Product Information-
     Each product has a desdicated details page displaying its name, category, current price, previous prices and available market price ranges.
     
### 4. Responsive User Interface-
    The website is designed to work across desktops, tables and mobile devices, ensuring a convenient browsing experience on different screen sizes.

### 5. User Authentication-
    The application integrates Better Auth to support user registration and sign-in, including Google and Github 0Auth authentication.
